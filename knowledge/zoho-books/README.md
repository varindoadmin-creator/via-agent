# Zoho Books knowledge sources

This knowledge area explains how Zoho Books works. It never stores current Varindo prices, stock, balances, credentials, or transaction status.

Official sources:

- Contacts: https://www.zoho.com/books/api/v3/contacts/
- Items: https://www.zoho.com/books/api/v3/items/
- Sales Orders: https://www.zoho.com/books/api/v3/sales-order/
- Purchase Orders: https://www.zoho.com/books/api/v3/purchase-order/
- Invoices: https://www.zoho.com/books/api/v3/invoices/
- OAuth: https://www.zoho.com/books/api/v3/oauth/
- Pagination: https://www.zoho.com/books/api/v3/pagination/

Stable VIA REST integrations remain the production data path because they provide controlled schemas, caching, logging, and write safeguards. Zoho MCP can be evaluated separately, but should not replace proven REST integrations without equivalent production controls.
